# Wiktionary Open Assistant — UX 改善版

Android で選択したテキストを、希望する言語版の Wiktionary で開くアプリです。
元の 2024 年頃のプロジェクトを、個人利用向けにシンプルに再構成しました。

## できること

- 他の Android アプリで文字列を選択し、選択メニューから **Wiktionaryで開く** を選択して調べる
- テキストの「共有」メニューからも起動する
- **自動検索**: 有効な言語を設定順に調べ、最も優先度の高い語の掲載先を開く
  - 3 言語ずつ並行確認して待ち時間を短縮
  - 見つからなければ英語版 Wiktionary の検索ページへ
- **毎回言語を選ぶ**: 通信を使った存在確認なしで、その言語版のページを開く
- 言語の有効／無効、上下移動、追加、削除、初期化
- 入力欄から検索動作を試す
- 言語設定を変更した瞬間に自動保存

## 改善・修正箇所

- 言語コードだけだった設定画面を、日本語名と明示的な操作ボタン付きの画面に変更
- 毎回開く全画面広告やバナーを削除し、広告 SDK／広告 ID 権限も削除
- 起動のたびに設定が初期化・肥大化し得た旧処理を修正
- 以前の `lang_pref` の番号付きキーを、初回起動時に新形式へ移行
- HTTP クエリを正しく URL エンコード
- `GlobalScope` とアプリ全体で共有していた mutable な言語リストを削除
- 通信タイムアウト、通信中の進行状況表示、キャンセル、手動選択を追加
- Java 17 の GitHub Actions ビルドへ更新

## ビルド方法

Android Studio でこのフォルダを開き、Android SDK 34 と JDK 17 を準備して Run するか、ターミナルで次を実行してください。

```bash
bash ./gradlew testDebugUnitTest assembleDebug
```

Debug APK は `app/build/outputs/apk/debug/app-debug.apk` に出力されます。
GitHub に push すると Actions の Artifacts から Debug APK を取得することもできます。

**重要:** このZIPにはビルド済みの新APKを入れていません。元のAPKに上書きインストールして設定を引き継ぐには、**元のAPKと同じ署名鍵**が必要です。異なる署名の Debug APK を使うために旧アプリをアンインストールすると、旧設定が消え、移行もできなくなります。まずアプリ設定をメモするか、署名鍵を確認してください。

## 技術仕様・留意事項

- アプリIDは元と同じ `jp.ooooiwocha.wiktionaryopenassistant`。既存の Android 設定移行を考慮したものです。
- 自動検索は選択語に関する `https://<言語コード>.wiktionary.org/w/api.php` の項目の有無を確認します。言語ごとの意味の判別はしていません。
- ネットワーク障害も「項目が見つからない」と同じ経路で扱われるため、接続障害時は英語版検索へ進むことがあります。
- 直接開くモードでは対象語の項目がない場合、Wiktionary の存在しないページへ進むことがあります。
- 手動追加した言語コードの文字種は検証しますが、その言語版 Wiktionary が実在するかまでは検証しません。
- 広告も独自の収集／分析機能も含みません。選択した語は検索のため Wiktionary に送信されます。
